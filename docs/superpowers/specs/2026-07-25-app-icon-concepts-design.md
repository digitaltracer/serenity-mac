# Serenity App Icon Concepts

## Goal

Generate four modern, minimal app-icon directions that reflect Serenity's role as a calm personal system for planning, journaling, goals, and AI-assisted insight.

## Shared visual language

- Use one bold, abstract symbol per icon.
- Use Serenity's cool blue and indigo palette.
- Favor clean geometry, balanced negative space, and restrained depth.
- Keep each symbol recognizable at 16 px.
- Avoid feathers, checkmarks, brains, sparkles, text, watermarks, and literal AI imagery.
- Produce square 1024 × 1024 preview artwork suitable for macOS and iOS icon evaluation.

## Concepts

1. **Still Point** — concentric soft arcs around a centered dot, expressing focus and calm amid complexity.
2. **Open Path** — a flowing path rising through layered planes, expressing progress without a literal checkmark.
3. **Horizon** — a luminous disk crossing a quiet horizon, expressing daily renewal and perspective.
4. **Constellation** — purposeful nodes gathered into a balanced orbit, expressing the app's connected planning, journal, goals, and insights.

## Deliverables

- Generate one polished image for each concept.
- Present all four concepts together for comparison.
- Keep these as non-destructive alternatives; do not replace the current app icon until the user selects one.

## Acceptance criteria

- Each direction is visually distinct.
- Each icon reads clearly at both full size and thumbnail size.
- The set feels modern, minimal, calm, and native to a premium Apple-platform app.
- No generated text, watermark, or unintended decorative detail appears.
